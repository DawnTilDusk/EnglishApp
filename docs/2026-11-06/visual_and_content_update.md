# 清爽花园视觉与题库扩充

## 视觉方向

浅灰绿背景、奶油白卡片、深绿色主操作，降低阴影和装饰强度。通过标题、正文、说明三层字体与统一间距组织信息；阅读正文保留更舒适的行高。

### Android

- 统一主题颜色、15 级文字样式、圆角、描边和轻阴影。
- 首页、学习中心、花园、个人页使用统一页头；学习模块自适应排列。
- 首页任务明确进度与开始/继续入口；底部导航采用图标与文字并列的紧凑布局。
- 首页活动日历改为本机真实活动记录，移除模拟色块；此数据包括应用活动，不代表知识掌握程度。
- 登录页按宽度调整品牌区和表单，支持滚动、键盘避让及密码显隐；启动入口和应用图标统一为小芽视觉。
- 阅读/听力目录与答题选项统一白底卡片、清晰选中状态和留白。

### Web

- 登录页、教师及机构控制台共用颜色、卡片、表格、按钮和导航规范。
- 小屏导航可换行，表格在卡片内横向滚动；保留键盘焦点提示和减少动画偏好。
- `/design-preview` 仅在开发模式提供示例控制台，不读取业务数据；生产环境返回 404。
- `design/web-login-desktop.jpg`、`design/web-console-desktop.jpg` 是实际浏览器预览截图。控制台截图使用明确标注的示例数据。
- `design/web-console-mobile.jpg` 记录调整表格最小宽度前的窄屏状态。之后已加入卡片内横向滚动，最终移动端样式尚未重新截图验证。

## 提交前检查修正

Android Studio 检查报告 vector 不应放在 mipmap 目录。本轮将默认 vector 和 v26 adaptive-icon 一并移至 drawable-anydpi / drawable-anydpi-v26，并更新 Manifest 图标引用，保持不同 Android 版本的资源选择。IDE 同时报告序列化和 JUnit 无法解析，但 Gradle Kotlin 编译通过；这些依赖解析提示仍需在 IDE 完成 Gradle 同步后复查。

修正后 APK 构建成功，95 项单元测试全部通过。首次并行构建 JVM 原生内存分配失败；不修改项目配置，使用单工作线程、768MB 堆内存重试成功。该崩溃不应归因于源码编译错误。
