# 2026-11-06 第一阶段改进

## 行为变化

- 每日词汇任务按通过学习阶段的不同学习项累计，按用户、上海产品日、词书和单词去重。测评、回顾、复习会话不再被当作“完成 20 词”。
- 首页任务展示实际进度，提供开始/继续入口。阅读听力进入模式选择，写作直达作业列表；只有检测到可提交作文时才展示新的作文任务，检查失败提供重试。
- 任务完成与奖励处理分开保存；代币使用现有账本与云同步，露珠仍为本地能力，按实际发放和上限反馈。
- 结算结果在离开练习前写入持久队列，登录恢复和应用运行期间可重试；日任务的待发奖励也能重试。重复结果复用稳定引用，不以主界面内存集合为唯一去重依据。
- 阅读和听力保存内容、答案、阶段及提交状态；提交失败重试前检查服务端。响应丢失后的恢复使用服务端提交时间归属产品日。
- 词汇增加完整界面快照，保留中断时的轮次、队列、已获奖励计数和阶段；继续即时复习时转移快照所有权，切换词书清理当前用户的旧界面快照。
- 作文原文件复制到应用私有目录，保存本地引用与待提交状态。重进后可以重试；提交前确认服务端状态，不依赖临时 URI 或仅存在内存中的字节。
- 听力记录音频位置/设备朗读位置，恢复后默认暂停；练习计时在离开前台时停止。
- 试用期间暂停与中断不再新增枯树，旧枯树可以免费移除；提示文案同步调整。
- 学习中心隐藏尚未开放的模块；词汇、阅读、听力、写作提供内容问题反馈按钮，问题信息仅存本机，由用户主动复制交给教师。
- 最小诊断记录仅存本机，记录任务入口、练习开始/恢复、结果入队与结算状态；不记录答案正文、作文、令牌或签名 URL，诊断/反馈记录按 30 天清理。
