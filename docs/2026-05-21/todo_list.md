# Seedie App TODO List (2026-05-21)

> 汇总背单词主闭环稳定后的下一步工作清单，当前优先进入 `Profile`、词汇量看板，以及学习参数设置看板三条线，先补可见性与可配置能力，再继续扩长期复习。

## 一、Profile 资料页补齐
- [ ] **把当前 Profile 页从“资产展示”补成“个人资料 + 学习身份页”**: 在现有 `ProfileScreen` 基础上加入昵称、头像占位、年级/身份、当前词书、学习目标等信息，让用户能看到“我是谁、我在学什么”。
- [ ] **补编辑 Profile 的最小闭环**: 支持修改昵称、头像占位、个人签名或学习目标文案，先完成本地状态 + 数据持久化接口对接，再决定是否接云端同步。
- [ ] **加入账号与会话操作入口**: 在 Profile 或设置里提供退出登录、刷新资料、查看账号绑定状态等基础操作，避免个人页只有展示没有管理。
- [ ] **把代币/徽章与学习资料拆成清晰层级**: 现有 Profile 偏“奖励墙”，后续需要明确“个人资料区”和“成就资产区”的布局边界，避免信息混在一起。

## 二、词汇量看板与学习进度看板
- [ ] **在学习中心补“当前词书”信息卡**: 显示当前词书名称、词书摘要、总词数或当前学习批次位置，让用户知道自己在学哪一本。
- [ ] **补“当前词汇量/已掌握词数”核心指标**: 明确展示已学习、已掌握、待复习三个核心数字，优先保证和数据库状态一致。
- [ ] **补“本轮学习进度”看板**: 至少展示当前学习轮进度，例如本轮目标词数、已完成词数、待复习词数，帮助用户理解今天学到哪里。
- [ ] **评估是否把看板放在学习中心还是数据花园**: 学习中心适合即时学习状态，数据花园适合累计成长统计，后续需要决定展示边界，避免重复堆同类信息。
- [ ] **补词汇量口径说明**: 明确“已学习”“已掌握”“待复习”各自代表什么，避免用户把“今天见过”误解成“已经掌握”。

## 三、学习参数设置看板
- [ ] **新增背单词参数设置入口**: 提供一个统一入口管理词书、学习难度、每日目标等参数，避免这些能力散落在多个页面。
- [ ] **支持切换当前词书**: 至少完成“查看可用词书列表 -> 选择当前词书 -> 保存生效”的最小闭环，并明确切书后对当前学习进度的影响。
- [ ] **支持设置学习难度或强度档位**: 先定义最小可用参数，例如每日新词数、复习强度、提示严格度，避免一开始就做成过于细碎的高级设置。
- [ ] **支持设置每日学习目标**: 如每日目标词数、每日学习时长、今日提醒策略等，便于后续和任务系统、学习中心看板联动。
- [ ] **明确参数生效范围**: 词书切换、难度变化、每日目标调整后，是立即作用于下一轮学习，还是只对新建轮次生效，需要先写清规则。

## 四、数据与状态联动收尾
- [ ] **补用户配置持久化模型**: 为词书、难度、每日目标等设置预留统一的数据来源，避免先写死在 UI 状态里。
- [ ] **对齐学习中心读取逻辑**: `MainViewModel` 当前只读取待复习入口，后续需要扩成读取当前词书、已掌握数、学习进度等聚合数据。
- [ ] **梳理 Profile / 学习中心 / 设置页的数据职责**: 哪些数据属于账号资料，哪些属于学习统计，哪些属于学习配置，要在 ViewModel 和 Repository 层先分清。
- [ ] **避免新设置破坏现有学习轮恢复逻辑**: 参数落地时要保证不影响已经稳定的滚动学习、待复习入口和立即复习闭环。

## 五、UI 与交互层建议
- [ ] **Profile 页优先做信息结构，不急着堆视觉特效**: 先解决“资料是否完整、入口是否清晰”，再考虑头像装饰、卡面动效等增强项。
- [ ] **词汇量看板优先做可读性，不急着做复杂图表**: 先用清晰数字卡片和简短说明建立认知，再决定是否引入趋势图、热力图或成长曲线。
- [ ] **设置页优先做“少而清楚”的参数**: 不要一开始给太多开关，优先保留 3 到 5 个真正影响学习体验的关键设置。

## 六、建议开发顺序
- [ ] **第 1 优先级：词汇量看板**: 先把学习中心的“当前词书 / 已学 / 已掌握 / 待复习 / 本轮进度”补出来，用户能立刻看到进展。
- [ ] **第 2 优先级：学习参数设置看板**: 再补词书切换、难度和每日目标等设置，因为它们会影响后续学习行为与数据口径。
- [ ] **第 3 优先级：Profile 资料页**: 最后再把 Profile 从奖励展示扩成完整个人页，避免和学习主线并行改太多。

## 七、当前不建议先做的事
- [ ] **先不要进入长期复习曲线实现**: `nextReviewAt`、计划复习入口、返修池仍然属于后续阶段。
- [ ] **先不要做过重的数据可视化**: 在核心指标和统计口径未稳定前，不建议先上复杂图表。
- [ ] **先不要把设置项拆得过细**: 先完成词书、难度、每日目标三类核心参数，再看是否需要更多高级开关。
