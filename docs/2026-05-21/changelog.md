# Seedie App Changelog (2026-05-21)

> 记录本轮围绕背单词“立即复习”闭环收尾、学习轮游标续接、状态流转收口与回归文档补齐的实现进展与当前可验证状态。

## 本轮新增能力
- **复习完成态持久化已收口**: 立即复习结束后，单词状态、轮次状态与学习中心待复习入口现在走同一条收口主链，减少“页面已完成但入口残留”的竞态。
- **学习轮下一批词续接已修正**: 一轮学习完成后，词书游标会在进入完成态前先推进，重新开始学习时可继续进入下一批词。
- **立即复习状态流转已统一**: 当前已明确“学习完成 -> 待复习 -> 复习完成”主路径，并将复习词的离场结果收敛为“已掌握”或“打回后续学习”两类。
- **第四步回归文档已补齐**: `docs/2026-05-21` 下已新增专用立即复习回归清单，可直接用于手测与回归。

## 状态流转与数据层进展
- **复习写库主链已收敛**: 复习答对后不再依赖多处异步收口，而是由仓库统一完成单词状态更新与轮次完成判定。
- **轮次完成判定已明确**: 当前以“待复习池清空”作为立即复习完成的唯一判定口径，避免 UI 与数据库状态分叉。
- **空活动轮次已有兜底处理**: 若历史数据中残留“没有 active words 的 `ACTIVE` 轮次”，读取学习会话时会先做提升/清理，不再卡住下一轮学习。
- **`4` 连错策略已临时定型**: 当前版本不再把单词直接塞回同一复习会话中的学习队列，而是移出本轮复习，标记回学习，并在后续学习流程中从第 `1` 关重新开始。

## 文档与执行清单进展
- **开发顺序清单已同步到当前进度**: `word_refactor_dev_order_checklist.md` 已把步骤 `1/2/3` 更新为完成态，避免继续把已落地事项当作未来待办。
- **阶段任务清单已同步当前现实**: `word_refactor_stages_checklist.md` 已明确阶段 4 的两个关键问题已收口，并保留“补回归清单 / 评估自动化验证”为当前后续项。
- **立即复习回归清单已独立成文**: `word_review_regression_checklist.md` 已覆盖正常路径、延后路径、边界路径与重进路径，便于后续回归复用。

## 当前可验证结果
- **手动测试已通过**: 当前“学习完成 -> 立即复习 / 稍后再说 -> 返回学习中心 -> 再进入学习或复习”的主闭环已完成一轮人工验证。
- **待复习入口表现更稳定**: 复习完成后，学习中心不再错误保留旧的待复习入口。
- **下一轮学习续接正常**: 一轮彻底完成后，再次开始学习不会错误回到上一批词。
- **当前行为边界更清晰**: 现在可以明确回答“复习完成如何判定”“`4` 连错后词去哪”“为什么暂不做独立返修池”等关键实现问题。

## 当前实现边界
- **第四步目前以文档交付为主**: 当前已经有可执行的手测/回归清单，但还没有配套的自动化测试基建。
- **独立返修池仍未落地**: `4` 连错后的词虽然已能稳定退出当前待复习轮，但还没有独立返修轮或长期返修池。
- **长期复习仍未开始实现**: `nextReviewAt`、计划复习入口、长期记忆曲线等仍停留在后续阶段。
- **学习中心统计展示仍待补齐**: 当前主闭环已稳定，但阶段 5 的“当前词书 / 已学 / 已掌握 / 当前学习轮进度”展示还未完成。
