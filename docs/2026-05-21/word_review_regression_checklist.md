# 立即复习回归清单（2026-05-21）

> 用于回归当前“学习完成 -> 立即复习 / 稍后再说 -> 学习中心入口 -> 复习收口”的最小闭环。该清单基于 2026-05-21 当前代码行为整理，重点验证状态收口与入口表现是否一致。

## 一、执行原则

- 每条路径都至少验证一次“页面表现”和“状态结果”是否一致
- 若某条路径中途出现异常，不要直接跳下一条，先记录停留页面、入口状态和复现步骤
- 所有路径都默认从当前词书存在可学习词、且应用已正常启动开始
- 若需要重复验证，优先重新完成一轮学习生成新的待复习轮次

## 二、正常路径

### 用例 1：学习完成后立即进入复习并全部答对

**前置条件**

- 当前没有历史遗留的异常待复习轮次
- 完成一轮新的学习，进入学习完成页

**操作步骤**

1. 在学习完成页点击 `开始拼写复习`
2. 进入复习页后，依次把本轮待复习词全部答对
3. 完成复习后返回学习中心

**预期 UI 表现**

- 学习完成页能正常进入复习页
- 每答对一个词，当前词从复习流程中移除
- 最后一个词答对时，页面显示“本轮复习已全部完成”或等价完成提示
- 返回学习中心后，不再显示本轮旧的待复习入口

**预期状态结果**

- 本轮轮次状态已从 `REVIEW_PENDING` 收口为 `REVIEW_COMPLETED`
- 已答对单词不再停留在待复习池
- 学习中心重新进入 `单词复习` 时，不应再打开刚完成的旧轮次

### 用例 2：学习完成后点击 `稍后再说`，再回来继续复习并完成

**前置条件**

- 完成一轮新的学习，进入学习完成页

**操作步骤**

1. 在学习完成页点击 `稍后再说`
2. 返回学习中心，确认有待复习入口
3. 点击 `单词复习` 重新进入该轮复习
4. 将本轮剩余复习词全部完成

**预期 UI 表现**

- 点击 `稍后再说` 后不会直接丢失待复习入口
- 学习中心仍能看到待复习数量
- 再次进入复习时，能进入正确轮次而不是空页面
- 完成后，待复习入口消失

**预期状态结果**

- 点击 `稍后再说` 后轮次仍保持 `REVIEW_PENDING`
- 完成整轮复习后轮次变为 `REVIEW_COMPLETED`

## 三、边界路径

### 用例 3：复习中答错后继续完成

**前置条件**

- 当前存在一轮待复习词

**操作步骤**

1. 进入复习页
2. 对某个词故意答错 1 次
3. 继续完成该词和其余词的复习
4. 返回学习中心

**预期 UI 表现**

- 答错后，页面提示“已移到复习队尾”或等价文案
- 该词会在后续再次出现
- 整轮完成后，学习中心入口正常消失

**预期状态结果**

- 单次答错不会直接结束本轮复习
- 只有待复习池真正清空时，轮次才会收口完成

### 用例 4：复习超时后继续完成

**前置条件**

- 当前存在一轮待复习词

**操作步骤**

1. 进入复习页
2. 对某个词等待 `5` 秒以上，不提交答案
3. 观察首字母提示后继续答题
4. 最终完成整轮复习

**预期 UI 表现**

- `5` 秒后出现首字母提示
- 超时词回到复习队尾
- 之后仍可继续完成整轮复习

**预期状态结果**

- 超时不会直接把该词标记为掌握
- 超时不会异常结束当前轮次

### 用例 5：同一词连续拼错 `4` 次，触发打回学习

**前置条件**

- 当前存在一轮待复习词

**操作步骤**

1. 进入复习页
2. 对同一个词连续拼错 `4` 次
3. 观察提示文案
4. 继续完成本轮其余待复习词
5. 返回学习中心，随后重新进入学习流程

**预期 UI 表现**

- 第 `4` 次错误后，提示该词已移出本轮复习，并将在后续学习中从第 `1` 关重新开始
- 该词不再继续留在当前复习队列中
- 如果该词是本轮最后一个待复习词，则当前立即复习可直接结束

**预期状态结果**

- 该词从当前待复习池移除
- 该词被标记回学习，而不是保留在 `REVIEW_PENDING`
- 当前版本不要求在同一立即复习会话里立刻出现学习题
- 后续重新进入学习时，该词应作为学习流程中的词重新开始

## 四、重进路径

### 用例 6：完成复习后再次进入 `单词复习`

**前置条件**

- 已完整完成一轮立即复习

**操作步骤**

1. 返回学习中心
2. 立即再次点击 `单词复习`

**预期 UI 表现**

- 若没有新的待复习轮次，应提示暂无待复习单词或不给出可进入的旧轮次
- 不应再次进入刚完成的那一轮

**预期状态结果**

- 已完成轮次不会重复出现在待复习入口

### 用例 7：学习完成页出现后，退出当前页再回学习中心

**前置条件**

- 学习刚完成，完成页已经出现

**操作步骤**

1. 不进入复习，直接返回学习中心
2. 观察是否仍有待复习入口
3. 再从学习中心进入 `单词复习`

**预期 UI 表现**

- 学习中心仍可看到该轮待复习入口
- 重新进入时能进入正确轮次

**预期状态结果**

- 轮次在完成学习后已推进为 `REVIEW_PENDING`
- 不会因为离开完成页就丢失待复习状态

## 五、回归底线

- 学习滚动队列仍维持 `4` 个活跃词、`10` 个目标词的规则
- 学习中途退出后仍可恢复学习轮
- 学习完成后仍有 `开始拼写复习` / `稍后再说` 两条路径
- 完成复习后，学习中心不残留旧待复习入口
- `4` 连错后的词不会继续卡在当前待复习轮中

## 六、记录建议

- 每条用例记录一次：是否通过、异常页面、异常文案、是否可稳定复现
- 若失败，优先记录失败发生在：
  - 完成页进入复习前
  - 复习队列轮转中
  - 返回学习中心后入口状态
