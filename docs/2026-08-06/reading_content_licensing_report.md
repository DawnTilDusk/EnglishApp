# Seedie 阅读题库内容版权方案报告

| 项 | 内容 |
| --- | --- |
| 文档性质 | 决策汇报（供管理层审阅） |
| 日期 | 2026-08-06 |
| 产品 | Seedie（英语学习 + 游戏化激励；学生端 Android） |
| 议题 | 阅读理解题库的内容来源与版权合规路径 |
| 上架目标 | **国内安卓应用商店** |
| 内容定位 | **有合规练习即可**，不强制挂靠某教材 / 教辅品牌 |
| 建议结论 | **优先采用方案一（委托原创）**；方案二作扩量备选；方案三不建议作为上架前主路径 |

---

## 1. 背景与目标

### 1.1 业务背景

Seedie 学生端已具备阅读训练能力（自由刷题 + 教师作业），题库以远端数据库为唯一内容源（`reading_sets` / `reading_questions` / `reading_options`）。产品下一步需扩充更贴近真实教学场景的阅读材料，并准备在国内安卓软件商城上架。

若直接使用市面常用辅导资料或教材中的阅读篇章与原题，将涉及著作权与上架合规风险。本报告梳理三条可落地的合规路径，供决策。

### 1.2 成功标准

| 标准 | 说明 |
| --- | --- |
| 可上架 | 国内安卓商店审核及后续投诉场景下，能出示授权或自有版权证明 |
| 可采购 | 以当前团队规模与预算，现实中能谈成、能交付 |
| 可运营 | 许可范围覆盖 App 内展示、商业使用、后续版本更新；到期或终止有预案 |
| 够用即可 | 不追求「选自某某名校教辅」背书，年级难度与题型对标即可 |

### 1.3 明确不采纳的做法

以下做法**不作为方案选项**，仅作风险说明：

- 扫描 / OCR / 整理市面教辅、机构讲义后直接入库；
- 以「网上流传很广」为由，将中考真题整卷或教材原文商用收录；
- 无书面授权的「先上架、有问题再删」。

上述路径短期成本近乎为零，但面临下架、索赔、品牌受损，**不适合作为上架产品的内容策略**。

---

## 2. 三种方案总览

| 维度 | 方案一：委托原创 | 方案二：中小内容商数字授权 | 方案三：大社教材 / 知名教辅授权 |
| --- | --- | --- | --- |
| 核心做法 | 按规格外包或内部撰写原创短文与试题 | 向题库 / 内容工作室采购可上 App 的题包并签约 | 向出版社或大型教辅方采购数字再分发权 |
| 版权清晰度 | 高（著作权归属或永久授权写进合同） | 中高（取决于合同条款是否完整） | 高（谈成后最规范） |
| 采购难度 | 低，市场上写手与教研易找 | 中，需筛选真正愿签「App 再分发」的供应商 | 高，周期长、门槛与报价通常偏高 |
| 成本（同题量粗比） | 相对可控 | 中等（常为年费或题包费） | 最高 |
| 与「有练习即可」匹配度 | **最匹配** | 匹配 | 偏「品牌背书」，超出当前必要目标 |
| 上架前可落地性 | **高** | 中 | 低（不适合卡上架节奏） |
| 内容「像市面资料」程度 | 风格可对标，非原书原文 | 可接近教辅观感 | 最接近原版教材 / 教辅 |
| 推荐角色 | **上架前主路径** | 上线后扩量 / 补充 | 战略合作或远期选项 |

---

## 3. 方案一：委托原创（推荐主路径）

### 3.1 方案说明

按年级与题型标准，委托英语教研 / 写手创作**原创阅读短文 + 原创选择题 + 解析**，风格对标初中同步或中考常见题型，但**不改编某一本具体教辅的原文原题**。

对外表述建议使用：「分级阅读练习」「同步风格练习」，避免「选自××教材 / ××真题」。

### 3.2 适用条件

- 上架目标为国内安卓商店；
- 产品只要求「有合规练习」，不强制内容品牌联名；
- 希望尽快形成可上架题量，并保留后续自主扩容能力。

### 3.3 实施要点

**交付规格（写入采购 brief）：**

- 适用年级（如七上–九下，或中考总复习）；
- 每套：1 篇短文（约定词数区间）+ 4～5 道四选一 + 简短解析；
- 题材范围（校园、科普、故事、应用文等）；
- 明确禁止：改写某教辅原篇、照搬真题原文。

**合同要件（口头约定无效）：**

| 条款 | 要求 |
| --- | --- |
| 权利归属 | 著作权转让给公司，或授予永久、可再许可的 App 商业使用权 |
| 使用范围 | 含 Android 客户端展示、后续版本、商业运营 |
| 改编权 | 允许修改难度、增删题目、排版与标注 |
| 原创保证 | 乙方保证原创；侵权由乙方承担责任 |
| 交付物 | 可导入字段的文稿（篇章、题干、选项、答案、解析） |

**建议首批规模：** 约 40～80 套，满足上架演示与日常刷题；再按使用数据补量。

**存证：** 合同 PDF、付款凭证、每套作者与交付日期；必要时在题库侧标注 `license_type = original`。

### 3.4 优点

- 版权链条最短、最清晰，应对商店与投诉最省事；
- 采购门槛低，周期短，适合卡上架节点；
- 内容可完全贴合产品年级与题型规划，不受出版社目录束缚；
- 与当前「有练习即可」的产品定位一致，避免为品牌授权支付溢价。

### 3.5 风险与代价

- 需建立简易质检（难度、答案、是否像某套书）；
- 单套成本随教研资历浮动（市场常见为单套数十至约一两百元人民币量级，仅供谈价参考）；
- 不具备「人教 / 外研 / 某教辅」品牌背书（当前目标下可接受）。

### 3.6 与现有产品的衔接

不改变阅读模块产品形态，新内容导入现有远端题库即可；后续可增加来源 / 授权元数据字段，便于审计。

## 4. 方案二：采购中小内容商数字授权题包

### 4.1 方案说明

向中小型教辅工作室、教育内容公司或「题库 API / 题包」供应商采购**已写明可用于教育 App 再分发**的阅读题包，签订数字内容授权合同后入库。

### 4.2 适用条件

- 希望加快扩量，减少自建教研投入；
- 能接受按年或按题包付费；
- 商务侧有人负责筛选供应商并审合同。

### 4.3 合同必须覆盖的范围

| 条款 | 必须明确 |
| --- | --- |
| 用途 | 教育类 App 内练习（是否含广告 / 付费会员） |
| 载体 | Android；若未来有 iOS / Web 是否一并授权 |
| 地域 | 中国大陆或约定范围 |
| 期限 | 1～3 年或永久；到期续约与下架义务 |
| 独家性 | 非独家通常更便宜 |
| 改编权 | 能否改题、加解析、调难度 |
| 署名 | 是否必须展示「内容来自 XXX」 |
| 终止 | 授权结束后内容处理方式（删除 / 停止分发） |

### 4.4 优点

- 比大社授权更容易谈成；
- 可一次性获得较大题量，扩库快；
- 若合同完整，合规性可达到上架要求。

### 4.5 风险与代价

- 市面不少「题库」只许校内教学使用，**不许装进商业 App**——需逐份核验，不能只看报价；
- 授权到期后可能被迫下架大批题目，影响运营连续性；
- 内容质量与年级对齐度参差不齐，仍需抽检；
- 对供应商依赖高于方案一。

### 4.6 定位建议

作为**上线后扩量或补充包**更合适；上架前若时间紧，不宜把全部题量押在尚未谈成的供应商上。

---

## 5. 方案三：采购大社教材 / 知名教辅数字版权

### 5.1 方案说明

与人民出版社体系教辅、外语教学与研究出版社、大型教辅品牌等权利方谈判，取得教材阅读篇或品牌教辅在 App 内的**合法数字使用与再分发授权**，并按规定署名与展示。

### 5.2 适用条件

- 战略上需要「正版教材 / 名牌教辅」背书；
- 有充足预算、法务与较长商务周期；
- 产品愿意按权利方要求做标识、渠道与审计配合。

### 5.3 优点

- 谈成后版权叙事最强，品牌信任度最高；
- 内容与校内教学场景贴合度高，营销话术清晰。

### 5.4 风险与代价

- **难买、贵、慢**：不适合作为「即将上架」的主依赖；
- 授权范围常被切得很细（仅试读、仅某册、禁止改编等），容易与产品功能冲突；
- 当前已确认「有练习即可」、不强制品牌——投入产出比偏低；
- 若谈判未果，上架节奏会被拖住。

### 5.5 定位建议

列为**中长期战略选项**（例如机构合作、联名版本），**不建议作为国内安卓首发上架的前置条件**。

## 6. 综合对比与决策建议

### 6.1 决策矩阵（结合已确认前提）

前提回顾：

1. 上架目标 = 国内安卓商店；  
2. 内容目标 = 有合规练习即可，不强制教材 / 教辅品牌。

| 决策问题 | 更优选择 |
| --- | --- |
| 怎样最快合法凑齐上架题量？ | 方案一 |
| 怎样控制版权投诉与下架风险？ | 方案一（其次方案二且合同完整） |
| 怎样在上线后快速加量？ | 方案二（在方案一底座上叠加） |
| 是否值得为「选自某某书」付大社授权？ | 当前阶段：**否**（方案三缓议） |

### 6.2 建议结论

1. **立即执行方案一**：以委托原创建设首批阅读题库，完成合同与存证，导入现有阅读模块。  
2. **并行储备方案二**：接触 1～2 家可签 App 再分发条款的内容商，作扩量比价，不阻塞上架。  
3. **暂缓方案三**：待有明确品牌联名或机构客户需求时再启动大社商务。

### 6.3 建议上架口径（对商店 / 对外说明）

> 阅读练习内容为自主版权或已获合法授权，不含未经授权的第三方教材或教辅原文。

## 7. 落地节奏（供立项参考）

| 阶段 | 动作 | 产出 |
| --- | --- | --- |
| 第 1 周 | 确定年级范围、套数、预算上限；准备写手 brief 与合同模板 | 采购文件齐备 |
| 第 2～4 周 | 试稿 3～5 套质检通过后批量交付 | 首批 40～80 套原创题 |
| 同步 | 法务 / 财务完成签约与付款存证；内容入库与抽检 | 可上架题库 + 授权档案 |
| 上架后 | 按刷题与作业数据补量；视需要试点方案二题包 | 持续运营能力 |

（具体周次可按上架 Deadline 压缩或拉长。）

## 8. 附录

### 8.1 与产品现状的关系

- 阅读能力已上线；本议题主要是**内容权利与供货策略**，不改变「自由刷题 / 作业」产品结构。  
- 技术方案上可继续使用现有远端题库表；是否增加授权元数据字段，可在选定方案后由研发做最小改动。

### 8.2 国内安卓上架的并行事项（非本题库版权，但常被一并问到）

软著、隐私政策、适龄提示、各商店资质材料等需按目标商店清单并行准备；与题库版权是两条工作流，建议同步推进，避免「内容已合规但资质未齐」或相反。
